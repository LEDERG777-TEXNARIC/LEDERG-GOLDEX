# LEDERG Messenger

Self-hosted Telegram-style messenger for the LEDERG project.

## Основные возможности

- регистрация и вход по уникальному @username без номера телефона и e-mail;
- realtime online через WebSocket с зелёным индикатором только для реально подключённых пользователей;
- поиск по @username или имени;
- личные 1:1 чаты без выдачи им типа «группа»;
- история и realtime сообщения;
- typing/read события;
- профиль: имя, username, bio, аватар;
- смена username и пароля;
- приватность: видимость поиска, online, аватара и разрешение новых сообщений;
- блокировка пользователей;
- активные сессии/устройства и отзыв отдельных сессий;
- TOTP двухэтапная проверка;
- тёмная/светлая тема;
- размер текста и анимации;
- отправка по Enter;
- браузерные уведомления;
- персональные обои каждого личного чата;
- mute для отдельного чата;
- SQLite WAL, integrity_check, backup;
- автоматический GitHub autopilot и откат к last-known-good;
- порт 8000.

## Приватность и безопасность

LEDERG не требует телефон или e-mail для базового аккаунта. Пользователь может скрыть свой аккаунт из поиска, отключить online, скрыть аватар, запретить новые сообщения и блокировать пользователей.

JWT привязан к серверной сессии. Пользователь может завершать устройства и включить TOTP 2FA.

Стандартный access-log Uvicorn отключён, но CloudPub, ОС и другие сетевые компоненты могут иметь собственные технические журналы.

### Важное ограничение

Личные сообщения в текущей версии имеют серверную авторизацию и контроль доступа, но это ещё не полноценное end-to-end encryption. Сервер технически может видеть текст сообщения. Для E2EE нужен отдельный протокол ключей устройств, ротации ключей, проверки identity и защиты от повторной отправки.

## Настройки

Структура настроек вдохновлена категориями Telegram Web: профиль, приватность и безопасность, активные сессии, уведомления, тема, размер текста, анимации, клавиатура/отправка по Enter и фон чата. citehttps://translations.telegram.org/ru/webk/settings/

## Пути

Код: \`C:\LEDERG-MESSENGER\`  
Данные: \`C:\LEDERG-MESSENGER-DATA\`  
Локальный сервис: \`http://127.0.0.1:8000\`

CloudPub публикует локальный HTTP/WebSocket сервис на порту 8000.
